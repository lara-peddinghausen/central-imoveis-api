Central de Imóveis - Backend

Breve descrição do projeto:

- API REST para gerenciamento de administradores, imóveis, proprietários, pessoas, locações e financeiro(não implementado ainda).
- Autenticação via JWT para endpoints protegidos.
- Implementada com Spring Boot, Spring Security, JPA/Hibernate e Maven.

Principais pastas:

- `src/main/java`: código-fonte Java (controllers, services, repositories, models, dtos, security).
- `src/main/resources`: configurações (`application*.properties`) e templates.

Stack técnica:

- Java 17+
- Spring Boot
- Spring Security (JWT)
- Spring Data JPA
- Maven

Para a referência completa dos endpoints da API, consulte `docs/API.md`.
Para o fluxo do app e o mapeamento entre telas e controllers, consulte `docs/API-mapeamento.md`.
